Step 1 of 7

What is metagenomics?

Metagenomics sequences all the DNA in an environmental sample — soil, ocean, gut — without culturing any organisms first. From raw reads we assemble genomes, group contigs into bins, evaluate quality, and identify who's there. This workbench walks you through every step with a tiny demo dataset.

Step 2 of 7

Quality control

Before assembly, raw reads must be checked and cleaned. FastQC profiles read quality, adapter contamination, and GC content. Trimmomatic (or fastp) removes low-quality bases and adapter sequences. Poor QC here propagates errors through every downstream step.

Run FastQC
metalearn-demo
fastqc demo_R1.fastq demo_R2.fastq -o qc_output/

Step 3 of 7

Assembly

Assembly stitches overlapping short reads into longer contigs. For metagenomes, SPAdes (with the --meta flag) handles multiple organisms at different coverages simultaneously. Key metrics: N50 (half the assembly is in contigs this long or longer), total length, and largest contig.

Run metaSPAdes
spades.py --meta -1 clean_R1.fastq -2 clean_R2.fastq -o assembly/ -t 8 -m 32

Step 4 of 7

Binning

Binning groups contigs that likely came from the same organism into a bin. Tools like MetaBAT2 use two signals: tetranucleotide frequency (each genome has a characteristic DNA composition) and coverage depth (contigs from the same organism appear at similar depth). Each bin becomes a candidate MAG.

Map reads back to assembly
bwa mem assembly/contigs.fasta clean_R1.fastq clean_R2.fastq | samtools sort -o mapped.bam && samtools index mapped.bam
[bwa mem] Indexing reference… [bwa mem] Aligning reads… [samtools sort] Sorting BAM… [samtools index] Indexing BAM… Mapping complete Mapped reads: 2,284,112 / 2,318,744 (98.5%) Output: mapped.bam
Run MetaBAT2
jgi_summarize_bam_contig_depths --outputDepth depth.txt mapped.bam && metabat2 -i assembly/contigs.fasta -a depth.txt -o bins/bin

Step 5 of 7

MAG quality

CheckM evaluates each bin by searching for lineage-specific single-copy marker genes. A high-quality MAG (HQ) has >90% completeness and <5% contamination. Medium quality (MQ): >50% completeness, <10% contamination. Anything below is low quality and typically excluded from further analysis.

Run CheckM
checkm lineage_wf bins/ checkm_output/ -t 8 -x fa --tab_table -f checkm_results.tsv

Step 6 of 7

Taxonomy

GTDB-Tk classifies each MAG by placing it in a reference phylogenetic tree built from thousands of curated genomes. It uses marker genes shared across bacteria to compute evolutionary distance. The result is a full taxonomic lineage from domain to species — standardised on the GTDB taxonomy.

Run GTDB-Tk classify
gtdbtk classify_wf --genome_dir bins/ --out_dir gtdbtk_output/ --cpus 8 --extension fa
