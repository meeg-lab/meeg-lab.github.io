A handy reference for the Linux and Mac terminal commands you will use every day in bioinformatics work. Covers file management, process handling, permissions, networking, compression, SSH, and search.

Right-click the image below to download a high-resolution copy.

## How to use this

Print it once, pin it to your wall. Within a week the commands you actually use every day will sink in, and you'll only refer to the sheet when reaching for the rare ones (`tar xjf`, `ssh-copy-id`, etc.).
