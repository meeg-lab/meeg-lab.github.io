This course covers the core statistical methods used in biomedical research — hypothesis testing, linear and logistic regression, survival analysis, and an introduction to causal inference — using real data and modern tooling.

## Topics

1. Exploratory data analysis and visualization with `ggplot2`
2. Probability and inference for biomedical data
3. Linear regression and diagnostics
4. Logistic regression and odds ratios
5. Survival analysis (Kaplan-Meier, Cox)
6. Multiple testing
7. Introduction to causal inference
